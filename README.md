📝 To Do List App

A simple and interactive To Do List web application built using HTML, CSS, and JavaScript.
This project helps users manage their daily tasks efficiently with a clean and user-friendly interface.

🚀 Features
➕ Add new tasks easily
✔ Mark tasks as completed using checkbox
🗑 Delete tasks when finished
💾 Save tasks using localStorage (data persists after refresh)
📋 Display tasks dynamically using JavaScript DOM manipulation
🎨 Clean and modern UI design
🛠️ Built With
HTML5
CSS3
JavaScript (ES6)
LocalStorage API
DOM Manipulation
